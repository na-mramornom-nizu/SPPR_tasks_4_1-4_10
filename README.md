# Системы поддержки принятия решений: сетевая оптимизация

Ноутбук **`SPPR_network_4_1-4_10.ipynb`** содержит решения упражнений 4.1–4.10 главы 4 предоставленной методички `network.pdf`. Вычисленные таблицы и графики сохранены внутри файла и доступны при просмотре на GitHub.

| Задача | Содержание |
|---|---|
| 4.1 (a)–(e) | Расписание судей, покрытие DAG путями, поток, MILO и LP, ограничения рабочего времени |
| 4.2 | Маршрутизация по дереву кратчайших путей, алгоритм Дейкстры |
| 4.3 | Замена автомобиля: кратчайший путь в DAG на горизонте пяти лет |
| 4.4 | Назначение студентов проектам, поток минимальной стоимости |
| 4.5 | Паросочетание и сведение двудольного случая к максимальному потоку |
| 4.6 | Раскраска графа конфликтов картин, MILO |
| 4.7 | Минимальное остовное дерево кабельной сети |
| 4.8 | Ограничение степени: гамильтонов путь и сравнение с замкнутой TSP |
| 4.9 | Непересекающиеся по ребрам пути, максимальный поток и минимальный разрез |
| 4.10 | Теорема Менгера как следствие Max-Flow Min-Cut; теоретическое доказательство |

В каждом разделе приведены условие, данные, модель, искомые величины, решение и ответ. Там, где чисел в условии нет, явно указаны фиксированные демонстрационные данные. Ноутбук не требует внешних файлов или сетевого доступа при выполнении.

## Запуск

Проверенное окружение: Python 3.14, Pyomo 6.10.1, HiGHS 1.15.1. Версии библиотек зафиксированы в `requirements.txt`. HiGHS устанавливается через пакет `highspy`, отдельный исполняемый файл решателя не нужен.

```bash
python -m pip install -r requirements.txt
python -m pip install jupyterlab
python -m jupyterlab
```

Открыть `SPPR_network_4_1-4_10.ipynb` и выбрать **Kernel → Restart Kernel and Run All Cells**. Все импорты, настройка решателя и общие функции находятся в единственной setup-ячейке.

Пакетная проверка с новым ядром:

```bash
jupyter nbconvert --to notebook --execute --inplace --ExecutePreprocessor.timeout=180 SPPR_network_4_1-4_10.ipynb
```

## Уточнения постановок

- В 4.3 основной расчет не предполагает продажу автомобиля в конце пятого года. Вариант с конечной продажей разобран отдельно, поскольку цена пятилетнего автомобиля в таблице отсутствует.
- В 4.5 потоковая модель применяется к явно заданному двудольному примеру; общая модель паросочетания также приведена.
- В 4.6 объяснено дополнительное правило совместимости картин внутри стены-группы и отличие этой формализации от непосредственного физического соседства.
- В 4.8 исходное условие «не более двух» допускает путь; требование цикла рассмотрено отдельно как усиление.

Проверка: последовательное выполнение всех 13 вычислительных ячеек из чистого ядра; проверки допустимости и значений целевых функций встроены в код. Задача 4.10 содержит только Markdown.
